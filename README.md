# YVONNIE2005 Multi-Device WhatsApp Bot

A multi-device WhatsApp bot with QR pairing, numeric pairing codes, AI assistance, group commands and moderation alerts.

## Features
- Multi-device account support
- QR and pairing-code connection
- Group AI question answering
- Group rules and help commands
- PostgreSQL session storage
- Health monitoring
- Optional AI provider integration

## Hosting
Designed for Render Web Services.

## Important
This project uses an unofficial WhatsApp Web connection library. Use responsibly with accounts you control.
